# Aqsa Rashid Portfolio — SEO Strategy & Keyword Optimization Plan

This document outlines the Search Engine Optimization (SEO) strategy to rank Aqsa Rashid's portfolio website on Google and Bing for high-intent search queries.

---

## 1. Primary Keyword Pillars & Search Intent Analysis

Our strategy focuses on **Commercial & Transactional Intent** — capturing clients who are actively looking to hire a web/UI designer or agency partner.

| Service Pillar | Primary Target Keyword | Target Search Intent | Monthly Search Intent Profile |
| :--- | :--- | :--- | :--- |
| **Web UI/UX Design** | `Figma Web Designer` | Transactional | Startup founders, product managers, marketing leads looking for UI layout design |
| **Landing Page Design** | `Landing Page UI Designer` | Transactional | Business owners needing high-converting landing page designs |
| **Webflow Development** | `Figma to Webflow Designer` | Transactional | Clients wanting seamless Figma design + Webflow build |
| **Social Media Graphics** | `Social Media Graphic Designer` | Transactional / Commercial | Brands seeking monthly social carousel/ad creative design |
| **Brand & Visual Design** | `Freelance UI UX Designer` | Commercial | Agencies & businesses seeking remote design contract work |

## 5. Technical SEO Checklist for Build Phase

1. **Schema Markup (JSON-LD):** Implement `Person` and `ProfessionalService` structured data so Google displays rich snippets (Rating 5.0, Services, Contact, Location).
2. **Page Speed & Core Web Vitals:** Keep total page weight under 1.5MB, optimize WebP/AVIF images, and aim for 95+ Lighthouse score.
3. **Open Graph & Twitter Cards:** Custom social share preview images for LinkedIn, Twitter/X, and WhatsApp links.
4. **Semantic HTML5:** Strict use of `<header>`, `<main>`, `<section>`, `<article>`, `<footer>`, and heading hierarchy (`H1` -> `H2` -> `H3`).
5. **Accessibility (WCAG 2.1 AA):** High contrast text ratios, proper `alt` tags on all portfolio thumbnails, keyboard navigation.
